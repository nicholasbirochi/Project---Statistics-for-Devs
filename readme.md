# 📊 Pandas Revenue Challenge

A small Python exercise using **Pandas** and **Matplotlib**. It parses and sorts reference dates, calculates average sales, and creates monthly bar and line charts from values defined in the script.

## Requirements

```bash
pip install pandas matplotlib
```

## Run

From the repository root, run:

```bash
python FinalProject.py
```

The script prints the average sales and saves `bar_chart.png` and `line_chart.png` in the current working directory.
